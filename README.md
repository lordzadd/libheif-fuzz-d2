# libheif fuzzing campaign (D2 + D3, Track B)

This repository vendors libheif commit `08075aebcc0d9bf7d35f900c36114b1b6e90ed7d`
(libheif 1.23.4) and provides reproducible scripts for the D2 harness and the
D3 baseline campaign, crash analysis, mitigation, and replay.

All inputs are synthetic: the 133 upstream test fixtures in
`libheif/fuzzing/data/corpus` and mutations generated by libFuzzer. No real
user data is used anywhere in this repository.

## D2 harness (fixed input counts)

    git clone https://github.com/lordzadd/libheif-fuzz-d2.git
    cd libheif-fuzz-d2
    python3 harness/run.py

The runner builds all seven targets with Clang/libFuzzer and executes 1,000
inputs per target by default. Set `FUZZ_RUNS` to choose another count. See
`docs/D2.md` for the Track B attack-surface analysis.

## D3 baseline campaign

    bash scripts/build.sh
    D3_LABEL=baseline python3 harness/campaign.py

Defaults: 5 rounds x 30 s per target, 2 libFuzzer fork workers per target, 3
targets at once (6 nominal cores). The campaign writes a timestamped directory
under `results/d3/baseline-<UTC>/` containing `config.json`, `campaign.csv`,
`coverage_over_time.csv`, `coverage_functions.csv`, per-round logs, the growing
corpora, deduplicated crash artifacts, and `summary.json`.

## D3 crash analysis (reproduce, minimize, root cause)

    D3_CAMPAIGN_DIR=results/d3/baseline-<UTC> python3 harness/analyze.py

Writes `analysis/crashes.csv`, per-input original + minimized files, and raw
reproduction / minimization / stack-trace logs under `analysis/`.

## D3 replay (same inputs, only the build under test changes)

    D3_CAMPAIGN_DIR=results/d3/baseline-<UTC> D3_LABEL=baseline \
        python3 harness/replay.py
    # after building the fixed source into build-fixed:
    D3_CAMPAIGN_DIR=results/d3/baseline-<UTC> D3_LABEL=fixed \
        D3_BUILD_DIR=build-fixed python3 harness/replay.py
    # production-like config (no ASan/UBSan), for exploitability evidence:
    bash scripts/build_release.sh
    D3_CAMPAIGN_DIR=results/d3/baseline-<UTC> D3_LABEL=release \
        D3_BUILD_DIR=build-release python3 harness/replay.py

See `docs/D3.pdf` / `docs/D3.md` for the full report, raw-result paths, and the
AI-use appendix.
