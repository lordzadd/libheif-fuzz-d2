# D3 changelog: `d3-final` → `d3-final-2`

`d3-baseline` (`1f847a0`) and `d3-final` (`f0ff42e`) are unchanged. All work is
on branch `d3-review`; `d3-final-2` tags the commit with the updated report.

## Outcome

- **Goal:** one reproducible, minimised, ASan-detected memory-safety violation
  in the decode path, with root cause, exploitability call and class patch.
- **Result: not reached.** Campaign C ran 13.841 CPU-hours and 115 665 718
  executions under ASan and wrote **no artifact of any kind** (no crash, OOM,
  timeout or slow unit). There is no C3, no new patch, and no new impact claim.
  The null result is kept and strengthened.
- **New CPU-hours:** Campaign C 13.841; Campaign B + C **25.137 CPU-hours**,
  **203 839 045 executions** (B: 11.296 CPU-h, 88 173 327 execs).

## New and changed tooling

- `harness/d3/gen_seeds.py` (new): structured seed generator — complete HEIF
  containers with `unci` items for all seven unc decoder families,
  grid/overlay/iden composition, transforms, `cmpC`/`icef`, and with
  `--features regions,meta` region items and compressed metadata. Deterministic.
  The 700 seeds add +922…+1 570 edges per target over Campaign B's whole
  corpus (`results/long2{a,b}/seed_gain.csv`).
- `harness/d3/seed_gain.py` (new): coverage of B corpus vs seeds vs both.
- `harness/d3/cov_areas.py` (new): per-area line coverage with one rule.
- `harness/d3/tools/heif_check.cc` (new): decode checker for seed validation.
- `scripts/coverage_report_native.sh` (new): Docker-less coverage measurement.
- `scripts/run_campaign_c.sh` (new): every Campaign C step as run.
- `harness/d3/campaign.py`: the checkpoint thread no longer calls
  `proc.kill()` on a finished `CompletedProcess` at shutdown (it raised).
- `harness/d3/tables_d3.py`: Campaign C sections (phases, coverage, seed gain).
  The Campaign A/B sections of `results/D3_tables.md` are byte-identical to the
  previous version.
