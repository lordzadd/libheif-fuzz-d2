# D2 — Attack Surface and Working Harness

## 1. Attack surface analysis (Track B)

Entry points in libheif that parse untrusted input. All are reachable from the harnessed decode entry point.

| # | Entry point | Input it parses | Reachable from harness? |
|---|---|---|---|
| 1 | ISOBMFF box parser | Box headers and sizes | Yes (file_fuzzer) |
| 2 | Item/property parser | Item references and properties | Yes (api_fuzzer) |
| 3 | Image handle decode | Pixel data and metadata | Yes (file_fuzzer) |
| 4 | Color conversion | Color profiles and matrices | Yes (color_conversion_fuzzer) |
| 5 | Tile grid decode | Tile offsets and sizes | Yes (tile_fuzzer) |
| 6 | Sequence/track decode | Track boxes and samples | Yes (sequence_fuzzer) |
| 7 | Box-level parser | Individual boxes | Yes (box_fuzzer) |
| 8 | Encoder path | Encoding parameters | Build only (encoder_fuzzer) |

## 2. Programs and test cases

## 3. Repository

## 4. Exact commands to run the harness

```sh
git clone https://github.com/lordzadd/libheif-fuzz-d2.git
cd libheif-fuzz-d2
python3 harness/run.py
```

Optional:

```sh
python3 harness/run.py
```

The harness prints a JSON summary with `total_crashes` and writes `results/fuzz_results.csv`.
